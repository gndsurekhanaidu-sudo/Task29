# Task29
Seaborn Fundamentals

Project Description

This project focuses on creating statistical data visualizations using Python's Seaborn library. It demonstrates different types of graphs to understand and analyze data.

Objective

To learn how Seaborn simplifies statistical data visualization and helps identify patterns in datasets.

Tools & Technologies

- Python
- Pandas
- Seaborn
- Matplotlib
- Jupyter Notebook

Dataset

- Titanic Dataset
- Iris Dataset

Visualizations

The project includes the following visualizations:

1. Count Plot
2. Box Plot
3. Histogram
4. Scatter Plot
5. Bar Plot

Key Learnings

- Creating statistical visualizations using Seaborn.
- Understanding data distributions.
- Comparing different categories.
- Identifying relationships between variables.
- Understanding the difference between Seaborn and Matplotlib.

Conclusion

This project helped me understand how to use Seaborn to create meaningful statistical visualizations and interpret data patterns effectively.
